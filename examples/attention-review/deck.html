Attention 메커니즘 리뷰

Scaled dot-product attention이 토큰마다 “어디를 볼지”를 계산하는 방법 — 수식에서 숫자까지

10분 리뷰. 목표: 수식 한 줄을 실제 숫자로 따라가 보는 것. 순서: 왜 필요했나 → Q/K/V → 수식 → √dk → 데모 → 행렬/코드 → 실전 요소.

Motivation

왜 Attention인가

RNN encoder–decoder

  • 문장 전체를 고정 길이 벡터 하나에 압축
  • 문장이 길수록 앞부분 정보가 희미해짐
  • 토큰을 순서대로 처리 → 병렬화 어려움

Attention

  • 출력을 만들 때마다 입력 전체를 다시 본다
  • 관련 있는 위치에 큰 가중치 → 장거리 의존성
  • 모든 위치를 행렬 곱 한 번에 → 병렬화

Bahdanau et al., ICLR 2015 (RNN + attention) → Vaswani et al., NeurIPS 2017 (attention만으로 Transformer)

병목: 인코더가 문장을 벡터 하나로 요약해야 했던 것. Bahdanau attention이 이를 풀었고, Transformer는 RNN을 아예 빼고 attention만 남김. → 누르면 오른쪽 카드가 나타남.

Intuition

Query · Key · Value — 검색으로 이해하기

Query \(q_i\)

지금 토큰이 찾고 있는 것

\( q_i = x_i W_Q \)

Key \(k_j\)

각 토큰이 내건 색인표 — 무엇과 맞는지

\( k_j = x_j W_K \)

Value \(v_j\)

맞았을 때 실제로 가져갈 내용

\( v_j = x_j W_V \)

q와 k가 얼마나 맞는지(내적)를 재고, 그 비율대로 v를 섞는다.

같은 입력 x에서 세 개의 학습된 선형 사영으로 Q, K, V를 만든다. 검색 비유: 검색어(Q)를 색인(K)과 비교해서, 맞는 문서의 내용(V)을 가져온다. 차이: 하나만 고르는 게 아니라 점수 비율대로 섞는다(soft).

Scaled Dot-Product Attention

수식 한 줄

$$ \mathrm{Attention}(Q,K,V) = \mathrm{softmax}\!\left(\frac{QK^{\top}}{\sqrt{d_k}}\right)V $$

\(QK^{\top}\)

모든 query–key 쌍의 유사도 점수 (n×n)

\(\div\sqrt{d_k}\)

차원이 커져도 점수 크기를 일정하게

softmax

행마다 합이 1인 가중치로

\(\cdot\,V\)

가중치로 Value를 섞은 출력

\( Q, K \in \mathbb{R}^{n\times d_k},\; V \in \mathbb{R}^{n\times d_v} \) — n은 토큰 수 · Vaswani et al., 2017, Eq. (1)

왼쪽에서 오른쪽으로 읽기: 점수 → 스케일 → 정규화 → 가중합. 결과의 i번째 행 = i번째 토큰의 새 표현. 다음 슬라이드에서 √dk 이유, 그 다음 데모에서 이 네 단계를 숫자로 따라간다.

Why \(\sqrt{d_k}\)?

왜 \(\sqrt{d_k}\)로 나누는가

\(q, k\)의 각 성분이 평균 0, 분산 1이고 서로 독립이라면

$$ \mathrm{Var}(q\cdot k) = \sum_{i=1}^{d_k} \mathrm{Var}(q_i k_i) = d_k $$
  • \(d_k = 64\)이면 점수의 표준편차 ≈ 8
  • 큰 점수 → softmax가 한 토큰에 거의 1 → gradient ≈ 0
  • \(\sqrt{d_k}\)로 나누면 분산이 다시 1

데모에서 확인

다음 슬라이드에서 “√dₖ로 나누기”를 끄면 가중치가 한 토큰으로 더 쏠립니다.

논문 각주의 논증: 내적은 dk개 항의 합이라 분산이 dk에 비례. softmax 포화 영역에서는 기울기가 거의 0이라 학습이 느려진다. temperature를 √dk로 고정한 softmax라고 봐도 된다.

Demo · 한 문장에서 attention 가중치 계산하기

“it”은 어디를 볼까 — 단계별로

토큰을 클릭하면 query가 바뀜 · Esc: 컨트롤에서 빠져나오기

설명용 toy 값(dk=4, 손으로 정한 Q/K/V). 실제 학습된 가중치 아님을 먼저 말하기. 1) query "it" 선택 → 2) 모든 key → 3) 내적 점수(cat이 5.5로 최대) → 4) ÷2 → 5) softmax: cat 약 64% → 6) value 가중합으로 출력 z. 그다음 √dk 체크를 끄면 cat이 약 94%로 쏠리는 것 보여주기. 시간 남으면 "hungry"나 "ate"를 클릭. 끝나면 Esc 후 →.

Implementation

모든 query를 한 번에 — 행렬 곱

def attention(Q, K, V, mask=None):
    d_k = Q.size(-1)
    scores = Q @ K.transpose(-2, -1) / math.sqrt(d_k)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, -1e9)
    weights = scores.softmax(dim=-1)
    return weights @ V, weights
  • 데모의 한 행 계산 = 이 행렬의 한 줄
  • 비용 \(O(n^2 d)\) — 긴 시퀀스에서 병목
데모에서 한 query씩 한 계산을 모든 query에 대해 쌓으면 이 n×n 행렬. "it" 행을 보면 데모 결과와 같다. 코드는 7줄이면 끝. mask는 다음 슬라이드. n² 메모리가 긴 문맥에서 문제 → FlashAttention 등 후속 연구.

In Practice

실제 Transformer에서 붙는 것들

Multi-head

h개의 head가 각자 다른 \(W_Q, W_K, W_V\)로 서로 다른 관계를 병렬로 본다

\( \mathrm{Concat}(\mathrm{head}_1,\dots,\mathrm{head}_h)W^O \)

Causal mask

decoder는 미래 토큰의 점수를 \(-\infty\)로 → softmax 후 가중치 0

생성 시 다음 토큰을 미리 보지 않게

Self vs Cross

Self: Q, K, V 모두 같은 시퀀스
Cross: Q는 decoder, K·V는 encoder

번역·멀티모달 모델의 연결 고리

Base Transformer: d_model 512, h=8, head당 dk=64 → 전체 연산량은 single-head와 비슷. mask는 코드의 masked_fill 한 줄. cross-attention은 decoder query가 encoder 출력을 검색하는 구조.

Summary

정리

  • Attention = query와 key의 내적 점수 → softmax 가중치 → value 가중합
  • \(\sqrt{d_k}\) 스케일링은 softmax 포화를 막아 학습을 안정시킨다
  • 전체가 행렬 곱이라 병렬화가 쉽지만, 비용은 \(O(n^2)\)

Bahdanau, Cho, Bengio. Neural Machine Translation by Jointly Learning to Align and Translate. ICLR 2015.

Vaswani et al. Attention Is All You Need. NeurIPS 2017.
